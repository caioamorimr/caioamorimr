# Caio Amorim Ribeiro

Information Systems student at UFCIRJ, based in Nova Friburgo, Brazil. I write Java backends with Spring Boot, and I work on embedded Linux and multi-agent systems as a member of the chon-group.

## Projects

- [order-management-api](https://github.com/caioamorimr/order-management-api): REST API in Java 21 and Spring Boot with JWT and rotating refresh tokens, role-based access, an order status state machine, Flyway migrations, 127 tests and CI. The domain model comes from a course; the security layer and everything after it is my own work.
- [tv-box-linux](https://github.com/caioamorimr/tv-box-linux): documentation and scripts that turn RK322x TV boxes into Linux servers with a Wi-Fi access point. Tested on four models, with a script that tells apart the three Wi-Fi chips that showed up.
- [chon-collision-avoidance](https://github.com/caioamorimr/chon-collision-avoidance): Jason agents that drive a small tracked robot from chat commands, check a simulated traffic light before moving and back away from obstacles. Built by a team of six at the IEEE IES course and hackathon at UFSC.

## Contributions

- chonOS, the chon-group's Linux image for TV boxes: I wrote the image build and first-boot Wi-Fi setup scripts (private repository).
- [ChonBots](https://github.com/chon-group/ChonBots): examples for the 9-in-1 and HW262 Arduino shields.
- [WeGIA](https://github.com/LabRedesCefetRJ/WeGIA): fixes for reported security vulnerabilities, credit card payments through Pagar.me ([#1036](https://github.com/LabRedesCefetRJ/WeGIA/pull/1036)) and an SMTP email system that also sends receipts by email.
